# Catalogo Escursioni

Questo repository contiene esclusivamente dati (in formato JSON) utilizzati dal sito AMS-clone.
Il progetto è sviluppato con Astro e CSS puro, e include un design system artigianale in fase di costruzione. 

## Dove si trova il file
`/data/catalogo.json`

## Come aggiornare
1. Apri il file `catalogo.json`
2. Modifica i dati delle escursioni
3. Premi "Commit changes"

Il sito si aggiorna automaticamente entro pochi secondi.

## Campi principali
- `title`: nome dell’escursione
- `category`: categoria (escursione-locale, sardegna-corsica, internazionale)
- `dates`: elenco delle date disponibili
- `price`: prezzo

## Nessun deploy necessario
Il sito legge questo file direttamente dal server.
Ogni modifica è immediata.
